# Declash for Navisworks — downloads

**Declash** lets Claude run your Navisworks Manage coordination work: clash tests, grouping, viewpoints,
clash reports, BCF, issue registers, model QA, weekly progress and Excel — just by asking in a chat.

## Download
Get the newest **Declash_Setup_x.y.z.exe** from [Releases](https://github.com/osama-bim-tools/declash-releases/releases/latest).

## Install
1. Close Navisworks.
2. Run the Setup (no administrator rights needed) and tick your Navisworks Manage versions.
3. Quit Claude Desktop completely (right-click its icon next to the clock → Quit) and open it again.
4. Open Navisworks with your model and ask Claude, for example: *"health check declash"*.

## Privacy
Everything runs on your computer. Your models, reports and data never leave it, and nothing about you is collected.
The only internet use is a daily read of this repository's public `latest.json` to see whether a newer version exists
(you can switch it off: ask Claude *"turn off the Declash update check"*).

## Updates
When a new version is published here, Claude tells you. Say *"install the Declash update"*, close Navisworks,
and it installs by itself.
